# La température d'infusion

Le thé vert demande souvent une température modérée.

## Points importants

- **Éviter l'eau bouillante**.
- Respecter le temps d'*infusion*.
- <color #FF7D00>Attention à la température.</color>
- <u>Adapter selon le thé.</u>

### Préparation

1. Chauffer l'eau.
2. Mesurer les feuilles.
3. Laisser infuser.
